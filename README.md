# 🛒 Canhoteria

> E-commerce completo desenvolvido, publicado e entregue para operação real.

🔗 **Site no ar:** [canhoteria.com.br](https://canhoteria.com.br)

## Sobre o projeto

Loja virtual de uma estamparia de camisetas, construída do zero até a produção e entregue ao cliente, que hoje opera o site sozinho.

## Funcionalidades

- 🎨 **Tema-filho (child theme) customizado** a partir do tema **Extendable**, adaptado à identidade visual da marca
- 💳 **Pagamento online** com **Mercado Pago** (Pix e cartão, com desconto automático no Pix)
- 📦 **Frete calculado pelo CEP** direto no checkout com **Melhor Envio**, com frete grátis acima de um valor
- 🗂️ **Catálogo** com filtros por tipo e preço, guia de tamanhos e variações de cor e tamanho
- 🖼️ **Galeria de produto reescrita do zero**, porque a nativa não atendia o catálogo
- ⚖️ **Páginas legais** seguindo o Código de Defesa do Consumidor (arrependimento, troca e defeito)
- 📘 **Documentação passo a passo** para o cliente operar a loja sem suporte técnico

## Stack e infraestrutura

| Camada | Tecnologia |
|---|---|
| Plataforma | WordPress + WooCommerce |
| Tema | Child theme do Extendable |
| Banco de dados | MySQL |
| Hospedagem | Hospedagem compartilhada, operada via SSH e WP-CLI |
| Integrações | Mercado Pago, Melhor Envio |
| Produtividade | Ferramentas de IA aplicadas ao desenvolvimento |

## O que aprendi

- Colocar um sistema em **produção** e manter ele estável para um cliente real
- Como funcionam integrações com **gateways de pagamento** e **plataformas de logística**
- Estender um tema com **child theme** sem perder as atualizações do tema-base
- Que a entrega só termina quando o cliente consegue operar sozinho

# 🛒 Canhoteria

> E-commerce completo desenvolvido, publicado e **vendido** para operação real.

🔗 **Site no ar:** [canhoteria.com.br](https://canhoteria.com.br)

## Sobre o projeto

Loja virtual construída do zero até a produção: configuração do servidor, instalação da plataforma, integrações de pagamento e frete e entrega ao cliente final, que hoje opera o site.

## Funcionalidades

- 💳 **Pagamento online** integrado ao **Mercado Pago**
- 📦 **Cálculo de frete** em tempo real com **Melhor Envio**
- 🗂️ **Cadastro e gestão de produtos** pelo painel administrativo
- 🧾 Fluxo completo de pedido: carrinho → checkout → pagamento → envio

## Stack e infraestrutura

| Camada | Tecnologia |
|---|---|
| Servidor | Linux (LAMP) com acesso via SSH |
| Banco de dados | MySQL |
| Plataforma | WordPress |
| Integrações | API Mercado Pago, API Melhor Envio |
| Produtividade | Ferramentas de IA aplicadas ao desenvolvimento |

## O que aprendi

- Colocar um sistema em **produção** e manter ele estável para um cliente real
- Como funcionam integrações com **gateways de pagamento** e **APIs de logística**
- Administração básica de **servidor Linux**, banco MySQL e acesso remoto via SSH
- Levantar requisitos, entregar e transferir um projeto para outra pessoa operar
