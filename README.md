# 🛒 Canhoteria

> E-commerce completo desenvolvido, publicado e **vendido** para operação real.

🔗 **Site no ar:** [canhoteria.com.br](https://canhoteria.com.br)

## Sobre o projeto

Loja virtual construída do zero até a produção: configuração do servidor, instalação da plataforma, integrações de pagamento e frete e entrega ao cliente final, que hoje opera o site.

## Funcionalidades

- 💳 **Pagamento online** integrado ao **Mercado Pago**
- 📦 **Cálculo de frete** em tempo real com **Melhor Envio**
- 🗂️ **Cadastro e gestão de produtos** pelo painel administrativo
- 🧾 Fluxo completo de pedido: carrinho → checkout → pagamento → envio

## Stack e infraestrutura

| Camada | Tecnologia |
|---|---|
| Servidor | Linux (LAMP) com acesso via SSH |
| Banco de dados | MySQL |
| Plataforma | WordPress |
| Integrações | API Mercado Pago, API Melhor Envio |
| Produtividade | Ferramentas de IA aplicadas ao desenvolvimento |

## O que aprendi

- Colocar um sistema em **produção** e manter ele estável para um cliente real
- Como funcionam integrações com **gateways de pagamento** e **APIs de logística**
- Administração básica de **servidor Linux**, banco MySQL e acesso remoto via SSH
- Levantar requisitos, entregar e transferir um projeto para outra pessoa operar
